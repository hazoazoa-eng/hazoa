# 구글 드라이브 동영상 웹사이트

구글 드라이브에 올린 동영상을 웹페이지 안에서 바로 재생하는 정적 사이트입니다.
서버나 데이터베이스가 필요 없고, GitHub Pages로 무료 배포할 수 있습니다.

## 구조

```
index.html   페이지 뼈대 (플레이어 + 영상 목록)
style.css    디자인 (모바일 대응, 다크 모드)
app.js       videos.json을 읽어 목록을 만들고, 클릭하면 드라이브 플레이어로 재생
videos.json  영상 목록 ← 영상을 추가할 때는 이 파일만 수정
```

동작 방식: 드라이브 공유 링크에서 파일 ID를 뽑아
`https://drive.google.com/file/d/파일ID/preview` 주소를 `<iframe>`에 넣습니다.
이것이 구글이 공식으로 제공하는 임베드 방식입니다.

## 영상 추가 방법

1. 구글 드라이브에 동영상 업로드
2. 파일 우클릭 → **공유** → 일반 액세스를 **"링크가 있는 모든 사용자"(뷰어)** 로 변경
3. **링크 복사**
4. `videos.json`에 항목 추가

```json
{
  "title": "영상 제목",
  "description": "설명 (선택)",
  "url": "https://drive.google.com/file/d/1AbCdEf.../view?usp=sharing"
}
```

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 를 선택하면
`https://<사용자명>.github.io/<저장소명>/` 주소로 공개됩니다.

로컬에서 확인할 때는 파일을 더블클릭하지 말고 웹 서버로 여세요
(`fetch`가 `file://`에서 막힘):

```
python3 -m http.server 8000   # → http://localhost:8000
```

## 주의사항

- **공유 설정이 "제한됨"이면 재생되지 않습니다.** 방문자는 구글 로그인 + 권한이 있어야만 볼 수 있습니다.
- **업로드 직후엔 "동영상 처리 중"** 이 표시될 수 있습니다. 처리가 끝나면 재생됩니다.
- **조회가 많으면 드라이브가 일시적으로 차단**합니다("너무 많은 사용자가 이 파일을 보았습니다").
  드라이브는 동영상 호스팅 서비스가 아니므로, 방문자가 많은 사이트라면
  YouTube(일부 공개)나 Cloudflare Stream 같은 전용 서비스가 적합합니다.
- 플레이어 모양(자동재생, 컨트롤 등)은 구글 플레이어 그대로이며 바꿀 수 없습니다.
- `<video src="...uc?export=download">` 직접 재생 방식은 100MB 이상 파일에서 바이러스 검사 경고 페이지 때문에 깨지므로 사용하지 않습니다.
- 링크만 알면 누구나 드라이브에서 원본을 열거나 다운로드할 수 있습니다. 다운로드를 막으려면 공유 설정의 ⚙ → "뷰어 및 댓글 작성자에게 다운로드, 인쇄, 복사 옵션 표시" 체크를 해제하세요(완벽한 차단은 아님).
