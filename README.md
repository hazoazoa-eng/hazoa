# 구글 드라이브 동영상 웹사이트

구글 드라이브에 올린 동영상을 웹페이지 안에서 바로 재생하는 정적 사이트입니다.
서버나 데이터베이스가 필요 없고, GitHub Pages로 무료 배포할 수 있습니다.

## 구조

```
index.html   게시판 뼈대 (상단 바 + 목록 + 글 보기)
style.css    디자인 (모바일 중심, 다크 모드)
app.js       videos.json을 읽어 목록/글 화면을 그림
videos.json  게시판 이름과 글 목록 ← 글·영상을 추가할 때는 이 파일만 수정
```

- 목록 맨 위에 `reading`(읽는 책)이 나오고, 그 아래 논리 단계(`groups`: Logic 1, 2, …)가 눌러서 펼치는 묶음으로 나옵니다.
- 목록에서 글을 누르면 글 보기 화면으로 이동하고, 아래쪽 `‹ 이전` / `다음 ›`으로 글 사이를 이동합니다.
- 글 본문의 링크가 **구글 드라이브·유튜브 링크면 그 자리에서 바로 재생되는 플레이어**로 나오고,
  다른 링크는 일반 링크로 나옵니다.
- `"video": true`에 `url`이 비어 있으면 "영상 준비 중" 칸이 나옵니다. 링크만 채우면 플레이어로 바뀝니다.
- 오른쪽 위 체크 버튼은 "시청 완료" 표시입니다. 방문자 본인 브라우저에만 저장됩니다.
- 주소 `…/#3` 은 3번째 글로 바로 가는 링크입니다.

## 글 추가 방법

1. 구글 드라이브에 동영상 업로드
2. 파일 우클릭 → **공유** → 일반 액세스를 **"링크가 있는 모든 사용자"(뷰어)** 로 변경
3. **링크 복사**
4. `videos.json`에서 해당 논리 단계(`groups`)의 `posts`에 글 추가 (위에 있는 글이 1번)

```json
{
  "board": "게시판 이름",
  "reading": { "title": "Reading: 괴델, 에셔, 바흐", "url": "https://..." },
  "groups": [
    {
      "title": "Logic 3: 나만의 창작 루틴",
      "posts": [
        {
          "title": "논리 3주차 살롱 : 강의 영상",
          "items": [
            { "text": "오늘 강의 - 논리 3회차 : 제목" },
            { "text": "🎬 강의 영상", "url": "https://drive.google.com/file/d/1AbCdEf.../view?usp=sharing" }
          ]
        }
      ]
    }
  ]
}
```

단계 묶음 없이 쓰려면 예전처럼 최상위에 `"posts": [...]`를 두어도 됩니다(묶음 아래에 나옴).

`items`의 각 줄은 `text`(글), `url`(링크) 중 하나 또는 둘 다 쓸 수 있습니다.

## 배포 (GitHub Pages)

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 를 선택하면
`https://<사용자명>.github.io/<저장소명>/` 주소로 공개됩니다.

로컬에서 확인할 때는 파일을 더블클릭하지 말고 웹 서버로 여세요
(`fetch`가 `file://`에서 막힘):

```
python3 -m http.server 8000   # → http://localhost:8000
```

## 주의사항

- **공유 설정이 "제한됨"이면 재생되지 않습니다.** 방문자는 구글 로그인 + 권한이 있어야만 볼 수 있습니다.
- **업로드 직후엔 "동영상 처리 중"** 이 표시될 수 있습니다. 처리가 끝나면 재생됩니다.
- **조회가 많으면 드라이브가 일시적으로 차단**합니다("너무 많은 사용자가 이 파일을 보았습니다").
  드라이브는 동영상 호스팅 서비스가 아니므로, 방문자가 많은 사이트라면
  YouTube(일부 공개)나 Cloudflare Stream 같은 전용 서비스가 적합합니다.
- 플레이어 모양(자동재생, 컨트롤 등)은 구글 플레이어 그대로이며 바꿀 수 없습니다.
- `<video src="...uc?export=download">` 직접 재생 방식은 100MB 이상 파일에서 바이러스 검사 경고 페이지 때문에 깨지므로 사용하지 않습니다.
- 링크만 알면 누구나 드라이브에서 원본을 열거나 다운로드할 수 있습니다. 다운로드를 막으려면 공유 설정의 ⚙ → "뷰어 및 댓글 작성자에게 다운로드, 인쇄, 복사 옵션 표시" 체크를 해제하세요(완벽한 차단은 아님).
